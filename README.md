# jwtech-feed

Промежуточный YML-фид для магазина JWTech на tomas.kz.

Каждые 3 часа GitHub Actions забирает фид AL-Style (адрес хранится в секрете `FEED_URL`) и публикует
очищенную версию на GitHub Pages: `https://<аккаунт>.github.io/jwtech-feed/feed.xml`.

Что меняется по сравнению с исходным фидом:

| Правило | Как |
|---|---|
| Цена | дилерская + 10%, округление вверх до 10 тг (`MARKUP`, `ROUND_TO` в workflow) |
| Цена 0 или заглушка 1 тг у поставщика | товар «под заказ» без цены (`type="on.demand"`, порог `MIN_PRICE`) |
| Закупочная цена | удаляется |
| Уценка | удаляется (id с буквой на конце или «Уценка=Да») |
| Наличие | атрибут `available` + `quantity_in_stock`, как требует tomas.kz |
| Характеристики | без служебных полей (ТН ВЭД, НКТ, штрихкод, Kaspi и т.п.) и без дублей |

Защита: если исходный фид не скачался или в нём меньше 10 000 товаров, сборка падает,
а на Pages остаётся предыдущая версия. Так tomas.kz не уберёт товары в черновики из-за сбоя у поставщика.

Поменять наценку: `.github/workflows/feed.yml` → `MARKUP: "0.10"`.
Запустить вручную: вкладка Actions → «Сборка фида для tomas.kz» → Run workflow.
Статистика последней сборки: `https://<аккаунт>.github.io/jwtech-feed/`.
